CiteRank.com provides a REST API for managing organizations and retrieving analytics programmatically. All endpoints require Bearer token authentication.

**Base URL:** `https://app.citerank.com/api/v1`

The same reference is browsable inside the app at **Settings → API**, and the spec itself is served at
`https://app.citerank.com/api/v1/openapi.json`.

## Authentication

Include your API key in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_KEY
```

Organization owners and admins can issue API keys from **Settings → API Keys** in the organization's settings sidebar. Keys belong to the organization, not to a brand. A key is issued either read-only or read-write, and can be restricted to selected brands and given an expiry date. Each key starts with `citerank_` and is shown only once, when you create it.

A key can make 1,000 requests a minute. Past that, the API answers `429` with a `Retry-After` header.

The same data is available to AI assistants over the [MCP server](/docs/api/mcp), which speaks the same permissions and the same tenancy.

## Endpoints

Browse the available endpoints in the sidebar, grouped by resource:

- **Brands**: manage brand records
- **Tools**: one-shot helpers (e.g. brand analysis) that don't persist anything
- **Prompts**: manage brand prompts
- **Competitors**: manage brand competitors
- **Snapshots**: aggregated analytics snapshots for prompts
- **Reports**: generate and retrieve AI Share of Voice reports
- **Analytics**: visibility, share of voice, citations, per-model, prompt, and query fan-out metrics
- **Runs**: retrieve prompt evaluation runs
- **Tags**: list the prompt tags in use on a brand
- **Opportunities**: retrieve the latest generated brand opportunities
- **Organizations and billing**: inspect organization and subscription state
- **Models**: list the answer engines CiteRank.com tracks

The **Tools** and **Reports** endpoints, and deleting a prompt, are reserved for CiteRank.com's own admin keys, so an organization key receives `403` there. To stop tracking a prompt and keep its history, update it with `enabled: false`.
