CiteRank.com provides a REST API for managing organizations and retrieving analytics programmatically. All endpoints require Bearer token authentication.

**Base URL:** `https://app.citerank.com/api/v1`

The same reference is browsable in the dashboard at **Settings → API**, and the OpenAPI spec itself is served at
`https://app.citerank.com/api/v1/openapi.json`.

## Authentication

Include your API key in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_KEY
```

Organization owners and admins can issue API keys from **Settings → API Keys** in the organization's settings sidebar. Each key belongs to the organization and starts with `citerank_`. A key is issued either read-only or read-write, and can be restricted to selected brands and given an expiry date.

To work with the same data from an AI assistant, connect it to the [MCP server](/docs/api/mcp), which uses the same permissions and the same tenancy.

## Endpoints

Browse the available endpoints in the sidebar, grouped by resource:

- **Brands**: manage brand records
- **Prompts**: manage brand prompts
- **Competitors**: manage brand competitors
- **Snapshots**: aggregated analytics snapshots for prompts
- **Analytics**: visibility, share of voice, citations, per-model, prompt, and query fan-out metrics
- **Runs**: retrieve prompt evaluation runs
- **Tags**: list the prompt tags in use on a brand
- **Opportunities**: retrieve the latest generated brand opportunities
- **Organizations and billing**: inspect organization and subscription state
- **Models**: list the AI apps CiteRank.com tracks

The **Reports** and **Tools** endpoints, and deleting a prompt, are reserved for CiteRank.com's own admin keys, so an organization key receives `403` there. To stop tracking a prompt and keep its history, update it with `enabled: false`.
