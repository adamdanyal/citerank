# Four passes, every interface

Each interface is scored by Jev (jev-latest) from screenshots on four tests, as a percentage. A test passes at 67%.

1. **Simple:** could a 10-year-old use it?
2. **No-think:** can a first-time user do the main thing without thinking?
3. **Concise:** does it inform with the least writing?
4. **Sticky:** does it make people come back or take the next step?

Jev reads the 10-year-old test literally, so no business screen passes it; use it to rank screens, not as a pass mark.
